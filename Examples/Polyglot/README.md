# Polyglot Examples

Small, workshop-friendly examples showing how to orchestrate non-.NET services from a
.NET Aspire AppHost.

- **[Go](Go/)** — hosting a Go HTTP service with `Aspire.Hosting.Go` / `AddGoApp(...)`.
- **[Bun](Bun/)** — hosting a Bun HTTP service with `Aspire.Hosting.JavaScript` /
  `AddBunApp(...)`.

Each example is self-contained: its own AppHost project, its own service directory, and its
own README with prerequisites and run instructions. See each subfolder's README for details.
